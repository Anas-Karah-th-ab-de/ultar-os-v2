Ultar OS in a virtual machine

Try everything without changing anything on your computer.

QEMU

  1. Unpack the image and create a virtual disk

    xz -d ultar-os-<version>-installer-x86_64.img.xz
qemu-img create -f qcow2 ultar-disk.qcow2 32G

  2. Start the installer with UEFI (OVMF)

    The path of the OVMF file differs between systems. Add -enable-kvm where available for more speed.

    qemu-system-x86_64 -machine q35 -m 4G -smp 2 \
  -bios /usr/share/ovmf/OVMF.fd \
  -drive file=ultar-os-<version>-installer-x86_64.img,format=raw,if=virtio \
  -drive file=ultar-disk.qcow2,if=virtio \
  -device qemu-xhci -device usb-kbd -device usb-tablet

  3. Install, then start from the disk

    Choose ultar-disk.qcow2 in the “Disk” step. When it is done, remove the installer image line and start again.

VMware

  1. If the release has a VMware file

    Get it from the virtual machine page, unpack it and open the .vmx file in VMware Workstation.

  2. Otherwise: convert the installer image

    Convert the image into a VMware disk and add it to a new machine together with a second, empty disk. Choose UEFI firmware and turn Secure Boot off.

    qemu-img convert -O vmdk ultar-os-<version>-installer-x86_64.img ultar-installer.vmdk

Tip: VMware grabs free USB devices automatically. Disconnect a camera or stick from the machine if you need it on your computer.
