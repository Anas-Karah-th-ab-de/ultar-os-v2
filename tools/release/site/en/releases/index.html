Releases and status

Every release with its notes, files and signatures, and the honest status of the system.

Status today

Works in the current release

  • Start via UEFI on x86_64 computers, in VMware and QEMU
  • The desktop session: compositor, bar, lock screen, system dialogs
  • Store, Settings and Files as separate apps, and signed packages from the store server
  • Signed system updates on the two A/B copies with automatic fallback (over the network from 0.8.1)
  • End-to-end encrypted voice and video calls, with sound and USB cameras in the kernel
  • Files, text editor, terminal and a reading-mode browser

New in development

  • The graphical installation in sixteen steps, with a restart at the end
  • Encryption of the data partition with a passphrase and an unlock screen at start
  • SSH server on the Ultar kernel, and networking over a USB-C cable
  • The Servo web engine for the full browser (video and sound)

Not there yet

  • Wi-Fi drivers and graphics output on real hardware; starting directly on it is still being tested
  • Unlocking the disk with the device chip (TPM)
  • Office apps (PDF, Word, Excel) and voice control “Hey KM”
  • The phone version on a real phone, and the Ultar kernel for ARM64

Release channels

ChannelMeaning
stableThe channel for network updates of installed devices.
betaThe current installer image for computers – for testing.
experimentalEarly releases such as the phone release – for test devices only.

Versions are major.minor.patch; every release has a higher number, and a device never accepts an older version than it runs.
