Ultar Server

Ultar OS ohne Bildschirm: klein, abgeschottet und sicher aus der Ferne verwaltet.

Ein Abbild, Art „Server“

Kein eigener Download: das Installationsabbild holen und in Schritt 6 „Art der Installation“ Server wählen.

SSH nur mit Schlüsseln

Ein SSH-Server in Rust läuft direkt auf dem Ultar-Kern: Befehle, scp und sftp. Keine Kennwörter – nur eingetragene Schlüssel. In der Server-Art standardmäßig an.

Web-Verwaltung

Verwaltung über HTTPS mit eigenem Zertifikat, dessen Fingerabdruck auf der Konsole steht, Sperre nach Fehlversuchen. Dort werden SSH-Schlüssel eingetragen.

Schnelles Netz

10-Gigabit-Treiber (Intel E610) mit MSI-X-Unterbrechungen, Speicherschutz vor Geräten über VT-d und Netz über USB-C.

Abgeschottete Dienste

Jeder Dienst mit eigenem Benutzer, Speichergrenzen und den wenigsten Rechten; seine Datei begründet jedes Recht.

Teil des Geräteverbunds

Der Server kann Rechenleistung oder sein KI-Modell an Ihre anderen Geräte verleihen – mit Ihrer Erlaubnis.

Updates ohne Stillstand

Das Update geht in die zweite A/B-Kopie; startet die neue nicht, kehrt der Server selbst zurück.

Vom eigenen Rechner verbinden

ssh -p 2222 root@<address>
scp -P 2222 file root@<address>:/data/
sftp -P 2222 root@<address>

SSH auf dem Ultar-Kern, Netz über USB-C und MSI-X-Unterbrechungen sind neu in der Entwicklung und kommen mit den nächsten Ausgaben; das SSH-Empfangstempo wird noch verbessert.
