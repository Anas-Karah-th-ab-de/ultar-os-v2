Verify a download

Two minutes that make sure the file is ours and unchanged.

  1. Fingerprint (SHA-256)

    Compute the fingerprint and compare it with the value on the download page.

    sha256sum <file>                              # Linux
shasum -a 256 <file>                           # macOS
Get-FileHash <file> -Algorithm SHA256          # Windows PowerShell

  2. Signature (Ed25519)

    Download the .sig file and the key file ultar-allowed-signers, then check with ssh-keygen, which Linux, macOS and Windows 10/11 already have:

    ssh-keygen -Y verify -f ultar-allowed-signers -I release@ultar.code-craft.tech \
  -n ultar-release -s <file>.sig < <file>

  3. The result

    You must see Good "ultar-release" signature. Any other result: do not use the file and write to us.
