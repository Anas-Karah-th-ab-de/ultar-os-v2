Ultar OS on a phone

Experimental – for test phones only.

This package has not been started on a real phone yet. The phone may stop starting. Do not use a phone you need every day.

Samsung Galaxy A30 (SM-A305F)

  1. Turn on “OEM unlocking”

    In the phone's developer options, then unlock the boot loader.

  2. Make a full backup

    Ultar Flash reads and saves the partitions before writing anything.

  3. Write the package with Ultar Flash

    The package …-a30-linux.zip writes only the system and vbmeta partitions – never the boot loader or the modem. Ultar Flash is a Windows tool by KM Code Craft and is not offered for download here yet.

x86_64 devices and the emulator

The image …-phone-installer-x86_64.img.xz installs like the computer edition or in a virtual machine, and shows the phone interface.
