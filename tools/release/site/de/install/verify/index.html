Download prüfen

Zwei Minuten, die sicherstellen, dass die Datei von uns ist und unverändert.

  1. Fingerabdruck (SHA-256)

    Fingerabdruck berechnen und mit dem Wert auf der Download-Seite vergleichen.

    sha256sum <file>                              # Linux
shasum -a 256 <file>                           # macOS
Get-FileHash <file> -Algorithm SHA256          # Windows PowerShell

  2. Signatur (Ed25519)

    Die .sig-Datei und die Schlüsseldatei ultar-allowed-signers herunterladen und mit ssh-keygen prüfen, das Linux, macOS und Windows 10/11 mitbringen:

    ssh-keygen -Y verify -f ultar-allowed-signers -I release@ultar.code-craft.tech \
  -n ultar-release -s <file>.sig < <file>

  3. Das Ergebnis

    Sie müssen Good "ultar-release" signature sehen. Jedes andere Ergebnis: Datei nicht verwenden und uns schreiben.
