Questions and answers

Do I need an account?

No. The system, the store and updates work without an account. The account is for calls over the Ultar number and the mesh over the internet. More.

Does it run on my computer?

It needs an x86_64 computer with UEFI. Starting directly on real hardware is still being tested; the sure way today is a virtual machine. See tested hardware.

Can I install it beside another system?

Yes: the option “beside an existing system” writes only into the largest free region and shrinks or moves nothing. It is a beta, though – back up your data first.

Why must Secure Boot be off?

Because our own boot loader is not signed for Secure Boot yet. Everything after it is checked against our keys.

Do I lose data in an update?

No: an update writes only the second system copy; your data is in a separate partition. How updates work.

Which languages are there?

Arabic, English and German – Arabic right-to-left everywhere, digits always 0–9.

Can I run my existing programs?

That is our goal: programs from other systems run in an isolated area of their own. These components are in development.

Report a problem or ask a question

Write to info@code-craft.tech and mention:

  • The version (Settings → About)
  • The device or virtual machine
  • What you did, what you expected and what happened – with a screenshot if possible

For security issues: report a security issue.
