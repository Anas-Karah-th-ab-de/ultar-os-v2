Ultar Server

Ultar OS without a screen: small, isolated and managed remotely in safety.

One image, kind “server”

No separate download: get the installer image and choose server in step 6 “Kind of installation”.

SSH with keys only

An SSH server written in Rust runs directly on the Ultar kernel: commands, scp and sftp. No passwords – registered keys only. On by default in the server kind.

Web console

A management page over HTTPS with its own certificate whose fingerprint is shown on the console, locked after failed attempts. SSH keys are added there.

Fast networking

A 10-gigabit driver (Intel E610) with MSI-X interrupts, memory protection against devices through VT-d, and networking over USB-C.

Isolated services

Every service with its own user, memory limits and the fewest rights; its file explains every right it asks for.

Part of the device mesh

The server can lend its computing power or its AI model to your other devices – with your permission.

Updates without standstill

The update is written into the second A/B copy, and the server falls back by itself if the new one does not come up.

Connect from your computer

ssh -p 2222 root@<address>
scp -P 2222 file root@<address>:/data/
sftp -P 2222 root@<address>

SSH on the Ultar kernel, networking over USB-C and MSI-X interrupts are new in development and come with the next releases; the SSH receive speed is still being improved.
