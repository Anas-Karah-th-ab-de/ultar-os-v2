Ultar OS auf einem Rechner installieren

Für Desktop und Server – vom USB-Stick, in sechzehn kurzen Schritten.

Der Installer löscht die gewählte Platte vollständig (außer im Modus „neben einem vorhandenen System“). Testgerät oder leere Platte nehmen und vorher Daten sichern.

  1. Installationsabbild herunterladen

    Von der Download-Seite: die Datei ultar-os-…-installer-x86_64.img.xz mit der Signaturdatei .sig.

  2. Datei prüfen

    Fingerabdruck vergleichen und Signatur prüfen wie in der Prüfanleitung.

  3. Entpacken und auf einen USB-Stick schreiben

    Unter Linux oder macOS mit den Befehlen unten (/dev/sdX durch Ihren Stick ersetzen – alles darauf wird gelöscht). Unter Windows: mit 7-Zip entpacken, dann die .img-Datei mit einem Programm für Rohabbilder schreiben.

    xz -d ultar-os-<version>-installer-x86_64.img.xz
sudo dd if=ultar-os-<version>-installer-x86_64.img of=/dev/sdX bs=4M status=progress conv=fsync

  4. Vom Stick starten

    Das UEFI-Startmenü öffnen (oft F12, F11 oder Esc beim Einschalten) und den USB-Stick wählen. Vorher Secure Boot in den UEFI-Einstellungen ausschalten.

  5. Dem Installer folgen

    Sechzehn Schritte; vor dem Schreiben lässt sich jeder Schritt aus der Zusammenfassung ändern:

    1. Sprache – Arabisch, Englisch oder Deutsch – für Installer und System.
    2. Barrierefreiheit – Große Schrift und Bildschirmleser.
    3. Tastatur – Arabisch+Englisch, Englisch, Deutsch.
    4. Netzwerk – Optional – die Installation geht ohne Internet.
    5. Testen oder installieren – Das System vom Stick testen, ohne etwas auf der Platte zu ändern.
    6. Art der Installation – Desktop oder Server.
    7. Hardware und Treiber – Die signierten Treiber auf dem Installationsmedium werden selbst gewählt.
    8. Komponenten – Was Sie jetzt wollen; den Rest später aus dem Store.
    9. Extras – Updates während der Installation und Medien-Codecs.
    10. Datenträger – Ganze Platte, neben einem vorhandenen System nur im freien Platz, oder manuell.
    11. Verschlüsselung – Keine oder Passphrase (mindestens 12 Zeichen).
    12. Konto – Ihr Name, Benutzername, Gerätename und ein Kennwort (mindestens 8 Zeichen).
    13. Zeitzone – Damaskus zuerst, mit Sommerzeit.
    14. Zusammenfassung – Alles prüfen und das Löschen ausdrücklich bestätigen.
    15. Installation – Schreiben auf die Platte mit Fortschritt.
    16. Installation abgeschlossen – „Neu starten“ – den USB-Stick entfernen, wenn danach gefragt wird.

  6. Der erste Start

    Mit dem angelegten Konto anmelden. Das System übernimmt Sprache, Tastatur und Zeitzone, und der Store zeigt die gewählten, noch fehlenden Komponenten.

Wenn etwas nicht klappt

Der Rechner startet nicht vom Stick

Prüfen, dass der Rechner im UEFI-Modus ist (nicht Legacy/CSM), Secure Boot aus ist und das Abbild als Rohabbild geschrieben und nicht als Datei kopiert wurde.

Der Bildschirm bleibt auf echter Hardware schwarz

Der direkte Start auf echter Hardware wird noch geprüft. Probieren Sie eine virtuelle Maschine und nennen Sie uns Ihr Gerätemodell.

Die Platte ist zu klein

Der Installer zeigt das Minimum je Partition; eine größere Platte wählen oder Platz freimachen.
