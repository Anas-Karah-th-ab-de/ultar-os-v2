# Click list of the artboards (round 2)

Generated by `build.py` from the click register of the generator: every `<button>`, `<a>`, `<input>` and slider of every board carries `data-act`; the build fails when an element has none or the action is not defined in `actions.py`.
Ref = section of `docs/DESKTOP-SPEC.md`. **NEW** = not defined there; the text is the proposed definition (collected at the end).
Total: **1113 clickable elements on 37 boards**, 199 distinct actions, 72 of them with behaviour newly defined here.
