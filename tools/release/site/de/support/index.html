Häufige Fragen

Brauche ich ein Konto?

Nein. System, Store und Updates gehen ohne Konto. Das Konto ist für Anrufe über die Ultar-Nummer und den Verbund über das Internet. Mehr.

Läuft es auf meinem Rechner?

Es braucht einen x86_64-Rechner mit UEFI. Der direkte Start auf echter Hardware wird noch geprüft; sicher geht es heute in einer virtuellen Maschine. Siehe geprüfte Hardware.

Kann ich es neben einem anderen System installieren?

Ja: die Option „neben einem vorhandenen System“ schreibt nur in den größten freien Bereich und verkleinert oder verschiebt nichts. Es ist aber eine Beta – vorher Daten sichern.

Warum muss Secure Boot aus sein?

Weil unser eigener Lader noch nicht für Secure Boot signiert ist. Alles danach wird gegen unsere Schlüssel geprüft.

Verliere ich bei einem Update Daten?

Nein: ein Update schreibt nur die zweite Systemkopie; die Daten liegen in einer eigenen Partition. So funktionieren Updates.

Welche Sprachen gibt es?

Arabisch, Englisch und Deutsch – Arabisch von rechts nach links überall, Ziffern immer 0–9.

Kann ich meine bisherigen Programme nutzen?

Das ist unser Ziel: Programme anderer Systeme laufen in einem eigenen abgeschotteten Bereich. Diese Komponenten sind in Arbeit.

Fehler melden oder Frage stellen

Schreiben Sie an info@code-craft.tech und nennen Sie:

  • Die Version (Einstellungen → Info)
  • Das Gerät oder die virtuelle Maschine
  • Was Sie getan haben, was Sie erwartet haben und was passiert ist – wenn möglich mit Bildschirmfoto
