Geräteverbund

Handy, Rechner und Server – ein Team. Auf einem Gerät beginnen, auf dem anderen weitermachen.

Weitermachen, wo Sie aufgehört haben

Was auf einem Gerät offen ist, geht auf ein anderes gekoppeltes über. Nichts kommt ungefragt an: Das Zielgerät fragt immer, und bei mehreren Geräten fragt der Sender, welches.

  • Einmal koppeln mit einem sechsstelligen Code
  • Jede Verbindung Ende-zu-Ende verschlüsselt
  • Im selben Netz direkt, über Netze hinweg über das Relais unseres Servers
  • Rechte je Gerät und ein Aus-Schalter bis in den Kern

Ehrlicher Stand

Funktioniert in der aktuellen Ausgabe

  • Der Dienst, die Seite „Verbund“ in den Einstellungen mit Koppeln und Rechten, die Kachel in den Schnelleinstellungen, „Auf anderem Gerät weitermachen“ im App-Menü und die Frage am Zielgerät
  • Geprüft gegen unseren echten Server mit eingebauten Fehlern (Abbruch, Beschädigung, Verzögerung)

Noch nicht fertig

  • Erprobung auf echten Geräten, Fernansicht, Ton und Anrufe im Verbund
