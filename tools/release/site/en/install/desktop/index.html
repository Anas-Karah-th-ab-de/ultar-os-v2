Install Ultar OS on a computer

For desktop and server – from a USB stick, in sixteen short steps.

The installer erases the disk you choose completely (except in the “beside an existing system” mode). Use a test device or an empty disk and back up your data first.

  1. Download the installer image

    From the download page: the file ultar-os-…-installer-x86_64.img.xz with its .sig signature file.

  2. Verify the file

    Compare the fingerprint and check the signature as in the verification guide.

  3. Unpack and write the image to a USB stick

    On Linux or macOS with the commands below (change /dev/sdX to your stick – everything on it is erased). On Windows: unpack with 7-Zip, then write the .img file with a raw image writer.

    xz -d ultar-os-<version>-installer-x86_64.img.xz
sudo dd if=ultar-os-<version>-installer-x86_64.img of=/dev/sdX bs=4M status=progress conv=fsync

  4. Start from the stick

    Open the UEFI boot menu (often F12, F11 or Esc at power-on) and choose the USB stick. Turn Secure Boot off in the UEFI settings first.

  5. Follow the installer

    Sixteen steps; you can go back and edit any step from the summary before anything is written:

    1. Language – Arabic, English or German – for the installer and the system.
    2. Accessibility – Large text and screen reader.
    3. Keyboard – Arabic+English, English, German.
    4. Network – Optional – the installation works without internet.
    5. Try or install – Try the system from the stick without changing anything on the disk.
    6. Kind of installation – Desktop or server.
    7. Hardware and drivers – The signed drivers on the installation medium are chosen by themselves.
    8. Components – What you want now; the rest later from the store.
    9. Extras – Updates during installation and media codecs.
    10. Disk – The whole disk, beside an existing system in free space only, or manual.
    11. Encryption – None or a passphrase (at least 12 characters).
    12. Account – Your name, user name, device name and a password (at least 8 characters).
    13. Time zone – Damascus first, with daylight saving time.
    14. Summary – Check everything and confirm the erase explicitly.
    15. Installation – Writing to the disk with a progress bar.
    16. Installation finished – “Restart” – remove the USB stick when asked.

  6. The first start

    Sign in with the account you created. The system takes over your language, keyboard and time zone, and the store shows the components you chose that are not installed yet.

If something does not work

The computer does not start from the stick

Make sure the computer is in UEFI mode (not Legacy/CSM), Secure Boot is off, and the image was written as a raw image, not copied as a file.

The screen stays black on a real computer

Starting directly on real hardware is still being tested. Try a virtual machine and tell us your device model.

The disk is too small

The installer shows the minimum each partition needs; choose a bigger disk or free up space.
