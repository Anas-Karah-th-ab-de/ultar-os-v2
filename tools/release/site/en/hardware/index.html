Tested hardware

Which devices Ultar OS runs on today – honestly.

DeviceStatusNote
Virtual machine: QEMU and VMware (x86_64, UEFI)✓ WorksThe recommended way to try it. Start, desktop and installation are tested automatically.
Beelink GTi15 Ultra (Intel Core Ultra 9 285H)◐ Being testedStage 1 passed on the real processor (16 cores). 10-gigabit network (E610), Bluetooth BE200 and the SD reader work on the real hardware; graphics output, Wi-Fi and starting directly on it are in progress.
Lenovo ThinkPad P1○ PlannedTest device; not tested yet.
Samsung Galaxy A30 (SM-A305F)◐ ExperimentalPhone package on Samsung's kernel; not yet started on the phone.
USB cameras (UVC, MJPEG)✓ WorksFor video calls; tested with a Logitech C920.
USB keyboard and mouse✓ WorksIncluding plugging in and out while running.
Network over USB-C (RNDIS, CDC-ECM)◐ NewFor example tethering from a phone; tested in the emulator.

Requirements

  • An x86_64 computer with UEFI, Secure Boot turned off (the loader is not signed for it yet)
  • A USB stick with at least 8 GB for the installation
  • An empty disk or a test device – or free space beside an existing system
