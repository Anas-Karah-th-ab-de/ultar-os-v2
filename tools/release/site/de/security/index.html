Sicherheit und Datenschutz

Ihr Gerät vertraut unserem Server nicht: Es prüft alles, was es installiert, selbst.

Signaturen überall

  • Systemabbilder, System-Apps und Store sind mit getrennten Schlüsseln signiert. Auf unserem Server verwahrt sie ein eigenes Signierprogramm mit eigenem Benutzer, das nur Prüfsummen in festem Format signiert, die Anzahl begrenzt und jede Signatur protokolliert.
  • System-Updates haben einen eigenen Schlüssel: ein App-Schlüssel kann nie ein System-Update signieren. Ein Rückfallschutz verhindert ältere Fassungen.
  • Das Gerät prüft jede Signatur gegen die eingebauten vertrauenswürdigen Schlüssel und lehnt Unsigniertes oder mit widerrufenem Schlüssel Signiertes ab – egal, was der Server sagt.
  • Der Server hat keinen Fernzugriff auf Geräte: keine Befehle, keine Steuerung, keine stillen Installationen.

Anrufe, von denen der Server nichts weiß

  • Schlüssel, Stimme und Bild bleiben zwischen den beiden Geräten (X25519, ChaCha20-Poly1305), signiert mit dem Geräteschlüssel.
  • Beide sehen dieselbe 60-stellige Sicherheitsnummer zum Vergleichen und eine Warnung, wenn sich ein Schlüssel ändert.
  • Der Server verbindet nur: Er speichert und protokolliert nichts über den Anruf, und beide Seiten können ihre Adressen hinter dem Relais verbergen.

Auf Ihrem Gerät

  • Jede App und jeder Dienst mit den wenigsten Rechten; wichtige Dialoge kommen vom System und sind deutlich gekennzeichnet.
  • Verschlüsselung der Datenpartition mit Passphrase (neu in der Entwicklung).
  • Diagnose und Standort sind von Anfang an aus.

Selbst prüfen

Jeder Download kommt mit SHA-256-Fingerabdruck und Ed25519-Signatur. So prüfen Sie.
