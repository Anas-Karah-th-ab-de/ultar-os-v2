Ultar Server

Ultar OS بلا شاشة: صغير، معزول، ويُدار عن بعد بأمان.

صورة واحدة، نوع «خادم»

لا تحتاج إلى تنزيل منفصل: نزّل صورة التثبيت واختر في الخطوة 6 «نوع التثبيت» ← خادم.

SSH بمفاتيح فقط

خادم SSH مكتوب بلغة Rust يعمل مباشرة على نواة Ultar: أوامر وscp وsftp. لا كلمات مرور – المفاتيح المسجّلة فقط. مفعّل في نوع الخادم.

إدارة عبر الويب

واجهة إدارة عبر HTTPS بشهادة خاصة يظهر بصمتها على الشاشة، مع قفل بعد محاولات فاشلة. ومنها تُضاف مفاتيح SSH.

شبكة سريعة

تعريف 10 جيجابت (Intel E610) بمقاطعات MSI-X، وحماية الذاكرة من الأجهزة عبر VT-d، والشبكة عبر USB-C.

خدمات معزولة

كل خدمة بمستخدم خاص وحدود ذاكرة وأقل الصلاحيات، وتشرح ملفاتها سبب كل صلاحية.

جزء من مجموعة الأجهزة

يمكن للخادم أن يقرض قدرته الحسابية أو نموذج الذكاء الاصطناعي لأجهزتك الأخرى – بإذنك.

تحديثات بلا توقف

التحديث يُكتب في النسخة الثانية A/B، والخادم يعود تلقائياً إن لم تعمل النسخة الجديدة.

الاتصال من حاسوبك

ssh -p 2222 root@<address>
scp -P 2222 file root@<address>:/data/
sftp -P 2222 root@<address>

SSH على نواة Ultar والشبكة عبر USB-C ومقاطعات MSI-X جديدة قيد التطوير وتأتي مع الإصدارات القادمة؛ سرعة الاستقبال عبر SSH ما زالت قيد التحسين.
