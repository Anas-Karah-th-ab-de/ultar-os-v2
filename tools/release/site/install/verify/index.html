التحقق من التنزيل

دقيقتان تضمنان أن الملف منّا ولم يتغيّر.

  1. البصمة (SHA-256)

    احسب البصمة وقارنها بالقيمة المعروضة في صفحة التنزيل.

    sha256sum <file>                              # Linux
shasum -a 256 <file>                           # macOS
Get-FileHash <file> -Algorithm SHA256          # Windows PowerShell

  2. التوقيع (Ed25519)

    نزّل ملف ‎.sig وملف المفاتيح ultar-allowed-signers، ثم تحقّق بأداة ssh-keygen الموجودة في Linux وmacOS وWindows 10/11:

    ssh-keygen -Y verify -f ultar-allowed-signers -I release@ultar.code-craft.tech \
  -n ultar-release -s <file>.sig < <file>

  3. النتيجة

    يجب أن ترى Good "ultar-release" signature. أي نتيجة أخرى: لا تستخدم الملف واكتب إلينا.
